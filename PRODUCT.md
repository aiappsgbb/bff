## Platform

## Users

- Customer engineering leaders and platform teams planning or building an agentic software factory on GitHub.
- Partners building their own IP and services on top of the framework; specialized partners are how the initiative scales.
- Microsoft and GitHub field teams presenting the framework. The site is public, so field-only content (talk tracks, speaker notes) stays in the PPTX decks, not on the site.

## Product Purpose

The Bright Factory Framework (BFF) is Microsoft's opinionated framework for building agentic software factories: ideas come to life, agents do the heavy lifting, humans monitor and control. Success is a team that finds its autonomy level per work type, pilots it, and scales with measured evidence.

## Positioning

A bright factory is the opposite of a dark factory, where humans have no control. Humans set a reversible dimmer per work type (Low, Medium or High autonomy) and can dim back up at any time. The framework is built on GitHub, better with Microsoft, and open by design, so it meets customers where they are.

## Operating Context

- Docs site at <https://aiappsgbb.github.io/bff/>: fundamentals, framework, autonomy levels, playbooks, getting started, reference.
- A self-assessment that places one work type at a level, and draft playbooks per level.
- Demos built with the GitHub Copilot app and GitHub automations.
- PPTX decks (internal and customer versions) built from the same sources as `src/data/framework.json`.

## Capabilities and Constraints

- Public and customer-safe.
- Say "Copilot cloud agent".
- Label preview features; playbooks are drafts.
- Use Low, Medium and High autonomy as level names.
- Never mention OpenASF, GitHub Spark or GitHub Models.

## Brand Commitments

- Name: **Bright Factory Framework**. Subtitle: Microsoft opinionated framework for building agentic software factories.
- Imagery: LEGO toy-photography renders. Purple octocat characters are people, blue robots are agents, and yellow ducks are quality.
- Visual system: GitHub Universe style, recorded in `DESIGN.md`.

## Evidence on Hand

- Real: the framework data (`src/data/framework.json`, `src/data/content.ts`), the product catalogue with official links, DORA and SPACE references, and the LEGO renders in `src/assets/`.
- Absent and never to be fabricated: customer stories, logos, benchmarks and statistics.

## Product Principles

- Humans stay in control: autonomy is earned per work type and always reversible.
- Opinionated but open: a default path on GitHub and Microsoft that works with what customers already run.
- Prove with demos and evidence, not claims.
- Scale through partners who build on the framework.
