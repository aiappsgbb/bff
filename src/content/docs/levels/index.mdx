Some teams call these three levels crawl, walk and run.

## Set per work type

A factory doesn't have one level. Dependency upgrades might run lights-off while new features stay at medium autonomy and a regulated payment flow stays at low autonomy. Pick the level **for each work type**, based on its risk and the evidence you have.

## How to move up

1. **Prove the current level.** Gates run on every change, and the team trusts the evidence they produce.
2. **Strengthen one thing.** The weakest answer in the [self-assessment](/get-started/find-your-level/) is usually the next move.
3. **Move one work type, one level.** Measure it end to end against the same SLOs and [DORA baseline](/framework/measuring/) as before.
4. **Rehearse dimming back up.** Know the triggers and the switch before you need them. [How to dim back up →](/levels/dim-back-up/)
