At medium autonomy, agents do the work and people approve it. An agent triages the issues people write, Copilot cloud agent builds the eligible ones in parallel, and agentic workflows propose tests and docs. People set priorities, direct fixes, steer sessions and approve the merge.

This level is about scale with control: more work in flight, approvals based on risk, and every agent with its own identity and budget.

<Aside type="caution" title="Draft: being aligned">
The stages, products and demo below still describe a broader medium level, including agents drafting specs from signals, an SRE agent and agents fixing failing gates. The [medium autonomy playbook](/playbooks/medium/) now defines a narrower flow: people write the issues, there's no SRE integration, and a person directs every fix. The broader steps move to [high autonomy](/playbooks/high/). The rest of the framework hasn't been realigned yet.
</Aside>

## How the team works

Agents run in cloud sandboxes with Copilot cloud agent. Sessions are shared: anyone on the team can watch, steer or continue them in mission control, the Copilot app or GitHub Mobile. Work starts from issues people write, and from scheduled workflows for tests and docs. [How collaboration changes across the levels →](/framework/multiplayer/)
