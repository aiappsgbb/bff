## How the playbooks work

- **One playbook per level.** Run it once per work type you want to move.
- **Two tracks.** The **UI** track uses github.com, the Copilot app and Azure portals. The **CLI** track uses `gh`, the Copilot CLI and `az`. Your choice is remembered across pages.
- **Track your progress.** Mark steps done as you go. Progress is saved in your browser only.
- **Every playbook ends the same way:** the evidence you need to move up, and how to dim back up.
