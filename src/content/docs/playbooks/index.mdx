## How the playbooks work

- **One playbook per level.** Run it once per work type you want to move.
- **Prerequisites, steps and exit criteria.** Each playbook lists what you need before you start, the steps in order and the evidence that shows the level holds.
- **UI and CLI instructions are coming.** Detailed steps for github.com, the Copilot app and Azure portals, and for `gh`, the Copilot CLI and `az`, will follow.
- **Every playbook ends the same way:** the evidence you need to move up, and how to dim back up.
