## Two ways to use the framework

**Customers apply it directly.** Use the levels, playbooks and big picture to build your own factory, one work type at a time.

**Partners build on it.** The framework is composable by design, so partners can fill its components with their own IP and offer it as a product or a service. Specialised partners are how the bright factory reaches every industry and every team.

## How a partner engagement can run

1. **Assess.** Map the customer's work types to levels, and find the weakest foundations.
2. **Pilot.** Take one work type up one level, with the playbook and the customer's own tools.
3. **Prove.** Measure it end to end against the same SLOs, and rehearse dimming back up.
4. **Scale.** Repeat per work type and per team, and hand over the engineering loop or run it as a service.
